# Магнат — онлайн-мультиплеер (2–10 игроков)

Настольная экономическая игра: комнаты по коду, каждый играет со своего устройства.
Вся логика игры работает на сервере (Node.js + WebSocket), браузеры только рисуют доску и отправляют действия.

## Запуск у себя

```bash
npm install
npm start
# открой http://localhost:3000
```

Чтобы играть с друзьями из интернета, нужен публичный адрес: см. деплой ниже.

## Деплой (нужен хостинг с постоянным Node-процессом и WebSocket)

Vercel и Netlify не подойдут: там функции живут секунды и держать WebSocket-комнаты не могут.
Подойдут Render, Railway, Fly.io или любой VPS.

### Render (бесплатный тариф)
1. Залей папку в репозиторий на GitHub.
2. На render.com: New → Web Service → выбери репозиторий.
3. Build Command: `npm install`, Start Command: `npm start`. (Или просто возьми `render.yaml` из репозитория: New → Blueprint.)
4. Через минуту получишь адрес вида `https://magnat.onrender.com`. Отправляй друзьям.

На бесплатном тарифе сервер засыпает после 15 минут без трафика. Первое открытие после простоя занимает около минуты, а комнаты при перезапуске пропадают.

### Railway / Fly.io
Подходит та же схема: репозиторий, `npm start`, переменная `PORT` подставляется автоматически.

## Как играть
1. Один игрок нажимает «Создать комнату» и отправляет остальным код или ссылку.
2. В лобби можно добавить ботов, сменить фишки и выбрать стартовый капитал.
3. Хозяин комнаты нажимает «Начать игру».

Если связь пропала, за игрока ходит бот. Вернуться можно, открыв ту же страницу в том же браузере. На ход даётся 90 секунд.

## Фото городов и видео
- Фото городов подгружаются из Википедии (Wikimedia Commons) при открытии игры и кешируются в браузере. Нужен интернет. Чтобы поставить своё фото, впиши ссылку в `PHOTO_OVERRIDE` в `public/index.html`, например `PHOTO_OVERRIDE['Берлин']='https://...'`.
- По центру доски есть плеер YouTube. Вставь ссылку на видео или плейлист, и оно включится у всех игроков комнаты. Кнопка 📺 в боковой панели скрывает плеер, звук при этом продолжает играть. Ролики, у которых автор запретил встраивание, не откроются.

## Что где лежит
- `server.js`: HTTP, WebSocket, комнаты и игровой движок
- `public/data.js`: поле, карточки, фишки (общий файл для сервера и браузера). Названия клеток меняются здесь
- `public/index.html`: интерфейс
- `render.yaml`: конфиг для Render
