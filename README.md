# Магнат — онлайн-мультиплеер (2–12 игроков)

Настольная экономическая игра: комнаты по коду, каждый играет со своего устройства.
Вся логика игры работает на сервере (Node.js + WebSocket), браузеры только рисуют доску и отправляют действия.

## Запуск у себя

```bash
npm install
npm start
# открой http://localhost:3000
```

Чтобы играть с друзьями из интернета, нужен публичный адрес: см. деплой ниже.

## Деплой (нужен хостинг с постоянным Node-процессом и WebSocket)

Vercel и Netlify не подойдут: там функции живут секунды и держать WebSocket-комнаты не могут.
Подойдут Render, Railway, Fly.io или любой VPS.

### Render (бесплатный тариф)
1. Залей папку в репозиторий на GitHub.
2. На render.com: New → Web Service → выбери репозиторий.
3. Build Command: `npm install`, Start Command: `npm start`. (Или просто возьми `render.yaml` из репозитория: New → Blueprint.)
4. Через минуту получишь адрес вида `https://magnat.onrender.com`. Отправляй друзьям.

На бесплатном тарифе сервер засыпает после 15 минут без трафика. Первое открытие после простоя занимает около минуты, а комнаты при перезапуске пропадают.

### Railway / Fly.io
Подходит та же схема: репозиторий, `npm start`, переменная `PORT` подставляется автоматически.

## Как играть
1. Один игрок нажимает «Создать комнату» и отправляет остальным код или ссылку.
2. В лобби можно добавить ботов, сменить фишки и выбрать стартовый капитал.
3. Хозяин комнаты нажимает «Начать игру».

Если связь пропала, за игрока ходит бот. Вернуться можно, открыв ту же страницу в том же браузере. На ход даётся 90 секунд.

## Три карты
Карта выбирается по числу игроков автоматически, хозяин может выбрать вручную в лобби:
- **Классика:** 40 клеток, до 6 игроков.
- **Большая:** 48 клеток, 7–8 игроков (добавлены Джакарта, Сидней, Мельбурн, Шанхай, Интернет‑провайдер, Центральная станция и ещё две карточные клетки).
- **Гигант:** 56 клеток, 9–10 игроков (ещё Касабланка, Барселона, Краков, Милан, Осака, Амстердам, Морской порт и налог на недвижимость).
- **Мега:** 64 клетки, 11–12 игроков (ещё Лагос, новая фиолетовая группа Торонто, Ванкувер и Монреаль, Грузовой порт, Газовая служба и две карточные клетки).
Новые клетки и цены лежат в `public/data.js`, их можно менять.

## Правила и настройки комнаты
- **Кто ходит первым:** перед игрой каждый бросает кубики. У кого сумма больше, тот ходит первым, остальные идут по убыванию. При ничьей перебрасывают только спорящие.
- **Аукцион:** если игрок отказался покупать клетку, её продают всем с торгов. Ставки от $10, любой игрок может поднять ставку или спасовать. Торги закрываются, когда остаётся один участник или 11 секунд нет новых ставок. Хозяин комнаты может его отключить в лобби.
- **Джекпот на парковке (по желанию):** налоги копятся на клетке «Бесплатная парковка», и тот, кто на неё встанет, забирает всё.
- **Обмен и заклад:** в обмене можно просить деньги, которых у игрока сейчас нет, если у него хватает имущества под заклад. Предложение показывается в центре стола, клетки обмена мигают с подписью, кому они переходят. Пока предложение открыто, получатель может заложить имущество, и кнопка «Принять» откроется, когда денег хватит.
- **Чат:** в лобби и в игре, с быстрыми реакциями. История хранится 60 сообщений.
- **Кастомизация:** в лобби нажми на свою фишку, чтобы выбрать смайл (36 штук) и цвет (12 готовых или свой). Имя меняется там же. Кнопка 🎨 в игре переключает тему доски (классика, ночь, закат, монохром), это личная настройка.

## Фото городов и видео
- Фото городов подгружаются из Википедии (Wikimedia Commons) при открытии игры и кешируются в браузере. Нужен интернет. Чтобы поставить своё фото, впиши ссылку в `PHOTO_OVERRIDE` в `public/index.html`, например `PHOTO_OVERRIDE['Берлин']='https://...'`.
- По центру доски есть плеер YouTube. Вставь ссылку на видео или плейлист, и оно включится у всех игроков комнаты. Кнопка 📺 в боковой панели скрывает плеер, звук при этом продолжает играть. Ролики, у которых автор запретил встраивание, не откроются.

## Админ-консоль
Программа `admin.js` подключается к серверу и позволяет выдавать деньги, ставить баланс, переставлять фишки, раздавать клетки и отправлять в тюрьму или освобождать из неё.
1. На Render открой сервис → Environment → Add Environment Variable: имя `ADMIN_TOKEN`, значение длинная случайная строка (20+ символов). Сохрани, сервис перезапустится. Без этой переменной админ-доступ выключен.
2. На своём компьютере, в папке проекта (один раз `npm install`):
   - PowerShell: `$env:MAGNAT_TOKEN="твой-токен"; node admin.js wss://имя-сервиса.onrender.com`
3. Команды: `rooms`, `players КОД`, `cash КОД НОМЕР +500`, `setcash КОД НОМЕР 1500`, `tp КОД НОМЕР КЛЕТКА`, `own КОД КЛЕТКА НОМЕР`, `jail`, `free`.

Каждое действие админа попадает в журнал игры с пометкой 🛠, его видят все игроки. Токен никому не показывай и не выкладывай в репозиторий.

## Что где лежит
- `server.js`: HTTP, WebSocket, комнаты и игровой движок
- `admin.js`: админ-консоль (запускается у тебя на компьютере, на сервер не нужна)
- `public/data.js`: поле, карточки, фишки (общий файл для сервера и браузера). Названия клеток меняются здесь
- `public/index.html`: интерфейс
- `render.yaml`: конфиг для Render
